### Fixed
- **Multi-disc audiobook torrents import again** (#3139). A qBittorrent, Deluge or rTorrent download such as `Fjellvinden/Fjellvinden CD1/01 Spor 01.mp3` and `…/Fjellvinden CD2/01 Spor 01.mp3` was blocked with "two files in this download would be placed at the same path": the torrent's own folder was taken for the client's shared download folder, so each file was placed by its name alone. The folder is now placed whole with its disc folders, as it already was from Transmission; with multi-disc flattening on, or a per-track file template, the tracks are numbered across discs in disc order. Norwegian and Danish `Del 1` folders, and folders such as `Fjellvinden_Cd 01`, count as discs too. Blocked downloads import with **Retry import**.

### Changed
- **Audiobook torrents in their own folder are placed whole from every client** (#3139). A flat multi-file audiobook from qBittorrent, Deluge or rTorrent used to be placed file by file, taking only the audio. It is now placed as a folder, as from Transmission: cover art, `.nfo` and other files in the torrent's folder come along, and in move mode the torrent's folder is removed afterwards. A qBittorrent torrent added without a root folder is still placed file by file.
