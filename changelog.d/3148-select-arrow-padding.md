### Fixed
- **Dropdown arrows no longer cover the selected value** (#3148). Every dropdown set a compact right padding that left no room for its arrow, so a dropdown as wide as its longest option (Media type showing "Audiobook", Per page showing "50") drew the arrow over the end of it. Dropdowns now keep exactly the room the arrow takes, on desktop as on touch screens, and the Wanted page's Format column is wide enough for the format names in every language. The pager's "…" jump dropdown, meant to read as plain text, no longer draws an arrow at all.
